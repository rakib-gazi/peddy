# Project Name :
    My Project Name is Peddy.   

# Project Description :
    The Peddy is the finest solution for pet lover who want to adopt pet form online. 
    This website allows users to explore various pets available for adoption. 
    They can filter them by category, and sort them by price. 
    So it can be helpful for pet lover to find their lovely pet as their side for welcome. 
    This website provides a user-friendly interface for pet adoption.

# 5 key features of the project:
    Category Filtering: Users can filter pets by different categories.
    Sorting: Pets can be sorted by price, This will be helpful to find pets within their budget.
    Pet Details: When user click on details button then a modal provides detailed information about  the pet.
    Loading States: Users  can see the loading for 2 second while they want to see pet information by category.
    Responsive Design: This website designed to work well on Pc or laptop screen , Tablet device & Mobile  Device.

# Used ES6 Features:
    1.Arrow Functions.
    2.Template Literals.
    3.Async/Await function.
